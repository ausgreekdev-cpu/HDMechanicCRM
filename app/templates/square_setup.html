Square Payment Integration

Square is the recommended payment provider for HDMechanicCRM. Many mechanic shops already use Square POS terminals, making it a natural fit.

Required Environment Variables
VariableDescription
CRM_SQUARE_ACCESS_TOKENYour Square access token (OAuth or personal token)
CRM_SQUARE_LOCATION_IDYour Square location ID (found in Developer Dashboard)
CRM_SQUARE_ENVIRONMENTsandbox for testing, production for live
CRM_SQUARE_WEBHOOK_SIGNATURE_KEYWebhook signature key (for verifying webhook authenticity)

When CRM_SQUARE_ACCESS_TOKEN is not set, the CRM runs in demo mode — payments are simulated and no real charges occur.

Setup Steps
  1. Create a free Square Developer Account
  2. Create a new application in the Developer Dashboard
  3. Generate an access token (use sandbox token for testing)
  4. Copy your Location ID from the Locations page
  5. Add the variables above to your .env file
  6. Configure webhooks (see below) and set CRM_SQUARE_WEBHOOK_SIGNATURE_KEY
  7. Restart the CRM
Webhook Configuration

In the Square Developer Dashboard, add a webhook endpoint:

  • URL: https://your-domain.com/payments/webhook
  • Events to subscribe to:
    • payment.completed
    • subscription.created
    • subscription.canceled
POS Integration

If you use a Square Terminal or Square POS at your shop, you can link the same Square account. Payments made through your POS will appear in the same Square Dashboard as online payments.

Learn more: Square Appointments | Square Point of Sale
